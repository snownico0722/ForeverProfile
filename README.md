# 阴阳省电 · YinYang Saver (WoW Forever)

一个小地图阴阳按钮，自动阶梯省电。支持 WoW Forever (Interface 16001)。

| 状态 | 画质 | 渲染比例 | 前台 FPS | 后台 FPS |
|---|---|---:|---:|---:|
| 阳面 · 正常 | 原始配置 | 原始配置 | 原设置 | 原设置 |
| 阴面 · 标准（约 20） | 低画质，保留基本操作 | 35% | 20 | 10 |
| 阴面 · 极限（约 10） | 最低画质 | 10% | 3（若被限制则 8） | 3（若被限制则 8） |

## 安装与操作

将文件夹置于 `_forever_/Interface/AddOns/ForeverProfiles/`，其中应直接有 `ForeverProfiles.toc` 和 `YinYang.lua`。

- 点击小地图的 ☯：从阳面进入**标准省电**（不是直接进入最低画质）。
- 阴面下连续 **120 秒**没有游戏内输入：自动进入**极限省电**。
- 在极限档移动游戏内鼠标、按鼠标或键盘：立即回到标准省电；新一轮 120 秒从最后一次输入起算。
- 再点击 ☯：恢复进入阴面前的**完整原始画质快照**，不保存用户自定义的两套画质。
- 3 FPS 只表示请求的客户端限帧值；如读回被客户端钳制到其他值，会回退到 8 FPS。即使读回是 3，也不能保证游戏实际渲染帧率小于 8，需实机确认。

## 设计边界

- 不修改 Windows 分辨率、显示器刷新率或电源计划；不自动制作物品。
- 只在阴面进行 0.25 秒一次的轻量鼠标位置采样。鼠标点击走游戏内全局事件；键盘监听透传，不占用快捷键。
- 输入探测限于 WoW 插件可见的输入。若客户端没有提供 `IsWindowFocused()`，游戏失去焦点后在其他窗口移动鼠标可能也被采样成活动，需要实机确认；客户端最小化时，定时器也依赖游戏 UI 继续运行。
- 保存变量 `ForeverYinYangDB` 记录原始画质，正常退出或 `/reload` 后仍可恢复。异常退出可能导致最近的快照未写盘。
- 任何不支持的 CVar 仍按现有 `Graphics.lua` 白名单跳过；部分失败会提示，不增加复杂回滚逻辑。
- 当前极限档不隐藏 `WorldFrame`，避免未经实测就假设能停止 3D 渲染或不影响制作队列。
